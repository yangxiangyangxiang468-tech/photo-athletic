# フォトアスレチック

写真を撮ると、それがアスレチックのコースになる横スクロールなしの1画面アクションゲーム。自分で作ったコースや、友だちにもらったコースでタイムを競う。

- `index.html` 1ファイルで動く（ビルド不要）。`manifest.webmanifest`・`sw.js`・`icons/` はホーム画面に追加してアプリとして使うためのもの
- iPhone: Safari で公開ページを開く → 共有 →「ホーム画面に追加」
- Android: Chrome で開くとホームに「ホーム画面に入れる」が出る（全画面で起動する）。LINE などアプリ内のブラウザでは「ブラウザで開く」に案内する
- アプリらしい手触り: スマホの「戻る」で前の画面へ、プレイ中と対戦の部屋では画面が消えない、プレイ中は横向きに固定（Android）、ミス・ゴール・スタートで振動（Android）、ピンチ拡大・ダブルタップ拡大・引っ張り更新・長押しメニューを止める

## 遊び方

- **コースを作る**: 写真を撮る（またはアルバムから選ぶ）と 40×22 マスのコースになる
  - 物のふち（横向きの輪郭）→ 薄い足場（下からすり抜けて乗れる）
  - 暗い所 → 地面（写真の中くらいの明るさよりはっきり暗いマスだけ。紙にペンで描いて撮れば自分でコースを描ける）
  - 色 → しかけ（赤 = トゲ、青 = 水、緑 = ジャンプ台）
  - 3つのルールはそれぞれオン/オフと量を調整でき、指で地面・足場・トゲ・水・ジャンプ台・スタート・ゴールを描き足せる
  - 自分でテストプレイしてゴールできたコースだけ保存できる（解けないコースを出さないため）
- **マイコース**: タイムアタック。自分のベスト（灰色）と作者（青）のゴーストが一緒に走る
- **送る**: コースをリンクにして送る。写真（縮小版）・マス・作者のタイムとゴーストを URL の `#s=` に圧縮して入れるので、サーバーは要らない
- **オンライン対戦**: 片方が部屋を作り、4文字のコードで相手が入る。どちらかがクリア済みのコースを出し、2人とも準備OKで3秒後にスタート。先にゴールした方の勝ち
  - ブラウザ同士の直接通信（WebRTC）。接続の仲介に [PeerJS](https://peerjs.com/) の無料サーバーを使う

## 操作

- スマホ: 横向き。左下の ◀ ▶ で移動、右下の JUMP でジャンプ（長押しで高く跳ぶ）
- パソコン: ←→ / A D で移動、スペース / ↑ / W / Z でジャンプ

## 構成（index.html 内）

- `==ENGINE START==` 〜 `==ENGINE END==`: 画面に触らない処理（写真の解析 `cellFeatures`・マス作り `buildTiles`・動き `stepPlayer`）。node で取り出してテストできる
- 保存はブラウザの localStorage（`pa_stages`）。写真は 640×352 の JPEG で入る
