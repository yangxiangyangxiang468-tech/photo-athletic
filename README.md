# フォトアスレチック

写真を撮ると、それがアスレチックのコースになる横スクロールなしの1画面アクションゲーム。自分で作ったコースや、友だちにもらったコースでタイムを競う。

- `index.html` 1ファイルで動く（ビルド不要）。`manifest.webmanifest`・`sw.js`・`icons/` はホーム画面に追加してアプリとして使うためのもの
- iPhone: Safari で公開ページを開く → 共有 →「ホーム画面に追加」
- Android: Chrome で開くとホームに「ホーム画面に入れる」が出る（全画面で起動する）。LINE などアプリ内のブラウザでは「ブラウザで開く」に案内する
- アプリらしい手触り: スマホの「戻る」で前の画面へ、プレイ中と対戦の部屋では画面が消えない、プレイ中は横向きに固定（Android）、ミス・ゴール・スタートで振動（Android）、ピンチ拡大・ダブルタップ拡大・引っ張り更新・長押しメニューを止める

## 遊び方

- **コースを作る**: 写真を撮る（またはアルバムから選ぶ）と 40×22 マスのコースになる
  - AI でモノを見つける → 地面（最初からオン）: ブラウザの中で動く AI（transformers.js の SegFormer-B0 ADE20K）が写真を1点ずつ150種類に塗り分け、壁・床・天井・空・窓・カーテン・じゅうたん・道路・草地など「うしろ」と照明（すり抜ける）（`SEG_BG`）以外は、ぜんぶモノとして形どおりに地面にする（マスの半分以上がモノなら地面）。初めてのときに約27MB（transformers.js 約0.9MB＋実行部品 約21.6MB＋モデル 約4.4MB）を読み込み、2回目からは端末に保存したものを使う。読み込めないとき（電波が無い）は下のやり方だけで作る
  - 空や壁 ↔ モノを見分ける → 地面（物そのものに乗れる。屋根・机・棚の上を歩けて、通り抜けはできない）。写真の上から空や壁など平らな「うしろ」を色のつながりで塗り広げ、残った所をモノとみなす。1マス幅の細い縦の物（電柱）は消し、1マスの厚さの横の物（電線）はすり抜けられる薄い足場にする。写真の上まで物で埋まっていて「うしろ」が見つからないときは使わない。地面は写真が透けて見える薄さで描く
  - 物のふち（横向きの輪郭）→ 薄い足場（下からすり抜けて乗れる）。最初はオフ。オンにしても遊ぶ画面では描かない
  - 暗い所 → 地面（最初はオフ。写真の中くらいの明るさよりはっきり暗いマスだけ。紙にペンで描いて撮れば自分でコースを描ける）
  - 色 → しかけ（赤 = トゲ、青 = 水、緑 = ジャンプ台）
  - 「モノを選ぶ」（最初に選ばれている道具）: 写真のどこにあるモノでも、押すとそのモノが地面になる。押した所から似た色でつながっている範囲をそのモノの形とみなす（`selectRegion`。木目や柄はまたげる）。色の違う部分（パソコンの画面と枠など）は、それぞれ押すと足せる
  - 手で描いたあとに「⚠ ゴールに届かない」と出たら、「足場を自動で足す」で届かない所に足場を足せる
  - 自動の見分けで写真のほとんどがモノになったとき（柄のある壁紙など）は、見分けられなかったとみなして使わない
  - 4つのルールはそれぞれオン/オフと量を調整でき、指で地面・足場・トゲ・水・ジャンプ台・スタート・ゴールを描き足せる
  - 写真に無い足場は足さない。自動で作ったコースは、スタートから実際に行ける所（`reach`：実際の動き `stepPlayer` で、標準より弱いジャンプ・遅い足で調べる）の中で一番遠い所をゴールにする（`chooseStartGoal`）。スタート・ゴールは写真のモノの上だけ（台は作らない。乗れるモノが1つも無い写真だけ、写真の下のふちを見えない床にする）。手で描き直したときは「ゴールまで行けるか」を表示する
  - 自分でテストプレイしてゴールできたコースだけ保存できる（解けないコースを出さないため）
- **写真のまま遊ぶ**: 写真から作った地面・足場（AI・空や壁の見分け・暗い所・「モノを選ぶ」）は、遊ぶ画面では何も描かず、写真に写っているモノにそのまま乗る（マスの種類 `PSOLID = 6`・`PPLAT = 7`。はたらきは地面・薄い足場と同じ）。作る画面ではうすく白く見せる。届かない所に足した足場、指で描いた地面・足場、トゲ・水・ジャンプ台・旗は見える。AI の四角は、四角のすぐ外と同じ色で続いている所（うしろ）を削ってモノの形に近づける（`refineBox`）
- **チェックポイント（途中の旗）**: 通ると緑になり、ミスするとそこから出直す（タイムは止まらない）。自動で作ったコースは、ゴールまでの道のりの途中に長さに応じて0〜3本置く（`placeCheckpoints`）。「旗（途中）」の道具で好きな所に立てられ、旗を押すと消える（5本まで）。リンク（`k`）とオンライン対戦にも入る。前からあるコースには付かない
  - 出直した瞬間にやられ続けないように、旗は「出てきて何もしなくてもその場に立てる所」（`safeSpot`）にしか立たない。手で押した所は近くの足場の上に寄せる（`snapFlag`）。描き直して足場が無くなった旗は外し、遊ぶときも危ない旗は使わない。それでも旗から出てすぐのミスが2回続いたらスタートから出直す
- **マイコース**: タイムアタック。自分のベスト（灰色）と作者（青）のゴーストが一緒に走る
- **送る**: コースをリンクにして送る。写真（縮小版）・マス・作者のタイムとゴーストを URL の `#s=` に圧縮して入れるので、サーバーは要らない
- **オンライン対戦**: 片方が部屋を作り、4文字のコードで相手が入る。どちらかがクリア済みのコースを出し、2人とも準備OKで3秒後にスタート。先にゴールした方の勝ち
  - ブラウザ同士の直接通信（WebRTC）。接続の仲介に [PeerJS](https://peerjs.com/) の無料サーバーを使う

## 操作

- スマホ: 横向き。左下の ◀ ▶ で移動、右下の JUMP でジャンプ（長押しで高く跳ぶ）
- パソコン: ←→ / A D で移動、スペース / ↑ / W / Z でジャンプ
- プレイ中の「⚙ 調整」: ジャンプの高さ・重さ・走る速さ・走り出し・止まりやすさ・空中での曲がりやすさ・ジャンプ台の高さ・ボタンの大きさをその場で変えられる（調整中は時間が止まる）。この端末だけの設定（localStorage の `pa_tune`）で、オンライン対戦では標準の動きになる。「数値をコピー」で今の値を文字にできる

## 構成（index.html 内）

- `==ENGINE START==` 〜 `==ENGINE END==`: 画面に触らない処理（写真の解析 `cellFeatures`・マス作り `buildTiles`・動き `stepPlayer`）。node で取り出してテストできる
- 保存はブラウザの localStorage（`pa_stages`）。写真は 640×352 の JPEG で入る
